# Historias de Usuario - Detalle y Criterios de Aceptación

## US-01: Registro de Usuario
- **Como:** Usuario nuevo[cite: 6]
- **Quiero:** Registrarme con mi correo y contraseña[cite: 6]
- **Para:** Poder utilizar la plataforma de forma segura[cite: 6].
- **Criterios de Aceptación:**
  - El usuario debe ingresar su nombre[cite: 6].
  - Debe ingresar un correo electrónico válido[cite: 6].
  - Debe ingresar una contraseña segura[cite: 6].
  - El sistema debe validar los datos[cite: 6].
  - El usuario debe recibir confirmación del registro[cite: 6].
- **Prioridad:** Alta | **Estimación:** 5 puntos[cite: 6]

## US-02: Inicio de Sesión
- **Como:** Usuario registrado[cite: 6]
- **Quiero:** Iniciar sesión en la aplicación[cite: 6]
- **Para:** Acceder a mi cuenta y rutinas[cite: 6].
- **Criterios de Aceptación:**
  - Ingresar credenciales válidas.
  - El sistema valida la información contra la base de datos del backend.
  - Redirección automática al panel principal o onboarding.
- **Prioridad:** Alta | **Estimación:** 3 puntos

## US-03: Onboarding Biométrico
- **Como:** Usuario en mi primer ingreso[cite: 1]
- **Quiero:** Completar un formulario con mis datos biométricos y objetivos[cite: 1]
- **Para:** Personalizar mis calorías, macronutrientes y rutina base[cite: 1].
- **Criterios de Aceptación:**
  - Ingreso validado de edad, peso y estatura.
  - Selección de objetivo físico (ganancia muscular, pérdida de grasa o mantenimiento)[cite: 1].
  - Generación automática de metas calóricas iniciales[cite: 1].
- **Prioridad:** Alta | **Estimación:** 5 puntos
