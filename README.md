# VitalFit

VitalFit es una plataforma tecnológica interactiva en formato de aplicación (SaaS / App de gimnasio) diseñada para unificar el entrenamiento en sala, el registro de cargas en tiempo real y el control nutricional, optimizando la retención de socios en centros deportivos y mejorando el progreso de los atletas[cite: 1].

## Equipo
- Deyaneira Gutierrez Mena (Backend, Base de Datos y Arquitectura)
- Frangelis (Frontend - Maquetación HTML y CSS)
- Isai (Frontend - Interactividad y Lógica con JavaScript)

## Tecnologías
- **Backend:** Java / Node.js con SQL Server / MySQL (Bases de datos y Endpoints).
- **Frontend:** HTML5, CSS3 (Diseño responsivo Mobile-First) y JavaScript.
- **Control de Versiones:** Git y GitHub.
- **Metodología:** Scrum (Organizado en Sprints de 1 semana).

## Organización del Repositorio
El proyecto se desarrolla utilizando Scrum y se organiza de la siguiente manera:
- `docs/`: Contiene la documentación ágil, el Product Backlog global, el detalle de las historias de usuario y la carpeta `sprints/` con el avance de cada iteración.
- `src/`: Contiene el código fuente del proyecto (Backend y Frontend).
